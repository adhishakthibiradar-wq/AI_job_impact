# AI Impact on Jobs Analysis

## Project Overview
An Excel dashboard analyzing the impact of Artificial Intelligence on employees, jobs, salaries, and productivity.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Interactive Dashboard

## Key Analysis
- AI adoption and automation risk
- Employee job status
- Salary changes before and after AI
- Productivity changes
- Industry-wise AI impact

## Dataset
2,000 employee records with 17 columns.

## Project File
AI_Job_Impact.xlsx
